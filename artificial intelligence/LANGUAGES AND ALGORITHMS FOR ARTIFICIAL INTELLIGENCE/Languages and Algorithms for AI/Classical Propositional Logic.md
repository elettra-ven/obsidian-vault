- **[[#1. Syntax for PL|Syntax]]**
	The rules that tell us how the well formed sentences are **constructed**.
	It tells us which are the **symbols** used to represent propositions, variables, functions, predicates, etc...
- **[[#2. Semantics for PL|Semantics]]**
	The rules which tell us the **meaning** of the well formed sentences.

>[!important] We hope that everything that is provable is a logical consequence and vice versa.

If the logic is very complex, there will unfortunately be unprovable axioms.

>[!info] Propositional Logic
>It's the simplest logic possible.
>Everything in this representation must be a proposition, a **sentence that can be true or false**.

## Connectives

 >[!warning] Connectives
 >In propositional logic we can build new propositions by connecting atomic sentences. 
 
 The connectives (finite set) are:
	 `and`, `or`, `not`, etc...
We stick to a selection of natural language connectives.

`if F then G` can be expressed as:
$$F \implies G$$
It doesn't necessary mean that $F$ is the **cause** of $G$, but rather that:
`G or not F`
$$G \vee \neg F$$
>[!warning] Exclusive OR and logical OR
>We must be careful when translating the natural language:
>"This happens OR this happens" models mutually exclusive events (**XOR**), while the logical OR can see both events happening together.

# Alphabet for PL
- propositions: $p_0, p_1, p_2, ..., A, B, C, ...$
- connectives: $\vee, \wedge, \rightarrow, \neg, \top, \perp, \leftrightarrow$
- auxiliary: $(...)$

## 1. Syntax for PL
Definition:
1) An **atom** is a formula
2) If $S$ is a formula, $\neg S$ is also a formula (**negation**)
3) If $S_1, S_2$ are formulas, $S_1 \wedge S_2$ is also a formula (**conjunction**)
4) If $S_1, S_2$ are formulas, $S_1 \vee S_2$ is also a formula (**disjunction**)
5) All well-formed formulas are generated by applying above rules

>[!quote] Shortcut
>$S_1 \rightarrow S_2$ can be written as $$\neg S_1 \vee S_2$$

### Concrete $vs$ Abstract syntax
$$A \wedge B \vee C$$
Is the **concrete syntax**, which can be interpreted in two **abstract** ways:
1) 
```
OR
|_ C
|
|_ AND
	|_ A
	|
	|_ B
```

2) 
```
AND
|_ A
|
|_ OR
	|_ B
	|
	|_ C
```

We must specify the correct syntax with **precedents** and **associativity rules**, like ==parenthesis==.
#### Precedents
$$\neg \gg \wedge \gg \vee \gg\ \rightarrow\ = \ \leftrightarrow$$
#### Associativity rules
$$\wedge, \vee, \rightarrow, \leftrightarrow$$

We say that every sentence is **==right-associative==**:
$$((A \wedge B) \vee C)$$
Option 1) was correct.

### Backus-Naur Form (BNF)

```
<formula> ::= Atomic Proposition
            | ¬ <formula>
            | <formula> ∧ <formula>
            | <formula> ∨ <formula>
            | <formula> → <formula>
            | <formula> ⇔ <formula>
            | ( <formula> )
```

## 2. Semantics for PL
We will work with a *finite set* of formulas.
We need the notion of **interpretation** in order to determine whether a proposition $A$ is true in a certain world.

>[!tip] Interpretation
>Given a propositional formula $G$, let $\{A_1,...,A_n\}$ be the set of variables which occur in the formula.
>An **interpretation** $I$ of $G$ is an **assignment** of truth variables to $\{A_1,...,A_n\}$.
>
>$G$ is said to be **True** in $I$ iff $G$ is evaluated **True** in the interpretation.
>
>If $G$ is **True** under $I$, we say that $I$ is a **model** for $G$:
>$$I \models G$$

Each atom $A_i$ can be assigned either **True** or **False** but never both.
### Truth Tables
It models the relationships between truth values of atoms and truth values of formulas.
*For example*:

|  P₁   |  P₂   | $\neg$P₁ | P₁ $\wedge$ P₂ | P₁ $\vee$ P₂ | P₁ $\rightarrow$ P₂ | P₁ $\leftrightarrow$ P₂ |
